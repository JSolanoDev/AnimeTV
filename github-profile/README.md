## Featured Project

### ZenkaiTV

ZenkaiTV is a responsive anime catalog and player for the web, phones, tablets, Android, and Android TV.

- Smart search, franchise-aware seasons, episode metadata, and weekly schedules.
- Multi-source playback with Google Cast controls and resilient fallbacks.
- English and Spanish metadata, favorites, history, and continue watching.
- Separate Android mobile/tablet and Android TV builds.
- Vercel CDN caching, request coalescing, and a regression-tested API layer.
